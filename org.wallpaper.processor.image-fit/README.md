# Still Image Fit

官方离线图像适配插件。与来源插件使用相同的独立 Wasm 包、校验和沙箱；不访问网络、文件系统或操作系统。

插件声明“填满屏幕、完整显示、拉伸、原尺寸、虚化背景”五个选项及对应的裁剪、缩放、叠放方案。核心仅执行通用图像合成原语，模式名称和具体方案属于插件。原图与元数据保持不变，派生图片放入便携缓存。

```bash
python scripts/package_plugins.py image-fit
```

Flutter 默认附带此包，首次运行时安装；用户通过插件页可启停或安装替代版本。第三方处理插件使用同一描述与处理协议，见仓库中的 `docs/PLUGIN_DEVELOPMENT.md`。当前协议提供离线图像合成；AI 补全所需的模型或经授权的网络处理能力尚未实现。
